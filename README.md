# Programación en Ambientes de Redes

Trabajos prácticos de la materia.

## Entorno

- **XAMPP 8.2.12** (Apache + PHP + MySQL) instalado en `C:\xampp`
- Carpeta de trabajo: `C:\xampp\htdocs\redes`
- Se accede en `http://localhost/redes/`

## Cómo levantar el servidor

1. Ejecutar `C:\xampp\xampp-control.exe` como administrador
2. **Start** en Apache (y MySQL si hace falta base de datos)
3. Abrir `http://localhost/redes/`

## Clases

- `clase1/` — HTTP: métodos, headers, códigos de estado
