Códigos de estado de una respuesta HTTP
Código Nombre Categoría Qué significa
200 OK Éxito El pedido salió bien y el recurso viaja en el body.
301 Moved Permanently Redirección El recurso cambió de dirección para siempre. La nueva va en el header Location.
304 Not Modified Redirección No cambió desde la última vez. El navegador usa lo que tiene en caché.
404 Not Found Error del cliente La URI pedida no existe en el servidor.
500 Internal Server Error Error del servidor Se rompió algo del lado del servidor procesando el pedido.
503 Service Unavailable Error del servidor El servidor está caído o saturado, pero de forma temporal.
